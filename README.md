# Blood Without Honor

A static site repository for the Realm’s expanded lore guidelines, designed to preserve canon, immersion, and historical consequence.

## Files

- `index.html` — main site shell and presentation
- `script.js` — the extended lore content rendered into the page

## Purpose

This repository presents the Realm’s lore as a readable, immersive, canon-first reference for players and staff. It expands the original ruleset with a fuller historical introduction, clearer explanation of the Lore Department, and broader world-context sections while preserving the original setting’s continuity and consequences.

## Notes

- The site uses a lightweight static JS rendering pattern.
- The original Storytelling references have been updated to the Lore Department throughout the expanded version.
